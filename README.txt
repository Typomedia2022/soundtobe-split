1) Pubblica questa cartella su Vercel (o Netlify Drop): nessun build necessario.
2) Apri il link in Chrome o Edge -> icona "Installa app" nella barra degli indirizzi.
3) Al primo avvio: "Salva archivio su file" e scegli una cartella (meglio se OneDrive/Dropbox).
   Da quel momento ogni modifica viene salvata automaticamente nel file.
4) "Importa rendiconto Excel" legge il foglio "Rendiconto" (riepilogo, brani, piattaforme).
